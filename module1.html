Module 1 - Electrical Department

This page provides learning resources, practical assessment records, trainer e-portfolio information, observation checklists and student portfolio records for learners undertaking Module 1 in the Electrical Department.

Module 1 focuses on practical electrical installation skills and workplace competency.

Learners are expected to demonstrate safe working practices, correct use of electrical tools and equipment, accurate installation procedures and quality workmanship.

Module 1 Learning Areas

PVC Sheathed System

Practical installation of electrical wiring using PVC sheathed cables, including preparation, cable routing, termination and testing.

View Learning Plan

Conduit Installation

Installation of electrical wiring systems using conduit, including measuring, cutting, bending, fixing, cable installation and termination.

View Learning Plan

Trunking Installation

Practical installation of electrical trunking systems including measuring, cutting, fixing, cable management and safe termination.

View Learning Plan
